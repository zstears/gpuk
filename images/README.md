# Images

Drop the article's hero illustration in this folder as **`hero.jpg`** and it will appear automatically on the article page.

- Wide shape, about 2400 × 840 px (roughly 3:1)
- JPG, ideally under 500 KB
- Keep the important part near the centre (the sides are cropped on phones)
- Use the exact lowercase name `hero.jpg`: GitHub Pages is case-sensitive

To use a PNG or a different name instead, change `images/hero.jpg` in the `.hero` style near the top of `index.html`.
